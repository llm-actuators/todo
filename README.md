# todo

> Priority-aware, Markdown-backed todo list for agent-cohort coordination.

Part of the [llm-actuators](https://github.com/llm-actuators) toolchain — single-purpose tools an LLM uses to act on real systems (devices, processes, files, other agents). Each binary is sterile: primitives only, domain knowledge lives in the model.

## What it does

A shared task ledger stored as Markdown, used to coordinate work across a cohort of agent seats: add/list/prioritize items, mark progress, and keep a durable record that survives session boundaries.
